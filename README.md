Here is (soon) a recreation of the old Radio Shack Electronic book, reduced to um, 8.5/11ths size? The 'booklet' print size that fits 2 full pages side by side on one sheet and often involves a staple. Don't build this just yet, we are checking resistor things because Ken is a troublemaker. See: Canadien Retrothings on the yew 2be.
 
## CBOARD directory ##
   the KiCAD 7 project to create the switch board. File list needs a haircut, also CoNect will have these boards for cheap soon. 

## OVERSHEET directory ##
   the FreeCAD 1.0 project to make the 'trampoline' keypads. If you just want to print one, ELECbook3.stl should be sliceable by most anything. 

## COVER SHEET (RSN) ##
   print this on the heaviest paper your printer allows, or add a liner sheet to double it up. Fold in half, print side out.

## PAGE PROTECTOR ##
   'inside load' sheet protector pouch for half sized (booklet sized) 3 hole binders

## ASSEMBLY ##
   stack the 3D printed oversheet (flat side up) over the completed circuit board - key 1 is top left. thin 2sided tape optional.
   Slip inside the folded cover sheet, fold outside 
   all this inside the plastic page protector.
